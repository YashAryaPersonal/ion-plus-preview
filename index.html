The Ion+ Language

A low-level, systems-oriented programming language bridging Python's elegant frontend architecture with the raw power of LLVM.

View on GitHub

🚀 We need developers and contributors

Ion+ is an ambitious open-source project (Apache 2.0). If you are passionate about compilers, AST design, LLVM, or building a powerful low-level OOP language inspired by C++, we invite all respectful developers to join us.

Frontend Pipeline

Built entirely in Python, the Ion+ frontend currently features a robust regex-based Lexer, comprehensive token enumeration, and indentation-sensitive block processing.

Low-Level Control

Designed for memory-aware operations. Ion+ supports pointers, bitwise operations, custom structures, enums, and explicit memory allocation.

Future LLVM Backend

The ultimate goal is lowering the Abstract Syntax Tree (AST) into LLVM IR for aggressive optimization, generating blazing-fast machine code.

# Sample Ion+ syntax demonstrating structures and control flow
struct Buffer:
    int size
    ptr byte data

?int Buffer.validate(int max_size):
    if size <= 0 or size >= max_size:
        return none

    int index = 0
    while index < 10:
        index += 1

    return index

Project Status

The project is currently conquering the frontend. The Lexer is fully operational, successfully scanning raw `.ionx` source files into token streams. The immediate next phase is building out the Recursive Descent Parser and structuring the AST nodes in Python.
